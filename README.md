🚀 Bizzas – Productivity Landing Page

✨ A modern and responsive productivity landing page built using React.js. Bizzas helps showcase productivity features, cloud storage, pricing plans, and customer testimonials through a clean and attractive user interface.

🌟 Features

- 🏠 Home Section – Attractive hero section with a clear call to action.
- 🧭 Responsive Navbar – Simple and user-friendly navigation.
- 💡 Our Features – Highlights the platform's key features.
- ☁️ Cloud Storage – Showcases cloud storage capabilities.
- 📊 Daily Analytics – Displays productivity and analytics features.
- 💎 Pricing Plans – Free, Pro, and Business plan sections.
- 💬 Testimonials – A dedicated section for customer feedback.
- 📱 Responsive UI – Designed for a clean browsing experience.

🛠️ Technologies Used

- ⚛️ React.js
- 🎨 CSS3
- 🟨 JavaScript
- ⚡ Vite
- 🧩 JSX
- 🌐 Netlify

⚙️ Installation & Setup

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder

cd day26

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Build for production

npm run build
